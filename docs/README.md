## How to use the guides

1. Open the guide for the exercise you are on.
2. Read **Goal** and **Starter** only.
3. Write the code in `src/bin/exNN.rs`.
4. Run it: `npm run ex -- exNN`.
5. Compare with **Expected output**.
6. Stuck? Open one hint at a time. Still stuck? Follow **Read & search**.
7. Done? **Stretch** goals are optional, but they are where the real learning is.

The guides deliberately do not include full solutions — the point is to
write the code yourself.
